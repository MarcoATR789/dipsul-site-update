# Supabase JS

SDK oficial `@supabase/supabase-js`, versão 2.118.0, distribuição UMD sem alterações.
Origem: pacote publicado no npm pelo projeto Supabase. Licença MIT em `LICENSE`.
Usado somente pela página administrativa, para autenticação, renovação da sessão e consultas com RLS.

Não contém credenciais. Não é servidor Node nem precisa de instalação no GitHub Pages.
Atualizações devem substituir o arquivo pelo UMD oficial e repetir os testes de autenticação.

Documentação: https://supabase.com/docs/reference/javascript/initializing
